The booklet is where the student's class record is kept. It follows the student throughout their Jiu-Jitsu journey: **one book per belt**.

It is where the instructor finds the information they need about the student. Whenever the instructor needs to confirm a student's status — before a class, a promotion test or a competition — they must consult the booklet.

## What the Instructor Finds in the Booklet

| Information | What it indicates |
| ----------- | ----------------- |
| Belt and stripe | The level the student currently holds. |
| Completed classes | How many classes the student has completed at the current stripe. |
| Competitions | How many competitions the student has taken part in. |

<Callout type="info">

This information determines whether the student is eligible for a promotion test. See [Test Requirements](../test/test-requirements) for the minimums required at each belt and stripe.

</Callout>

---

## Booklet Pages

The booklet is organized into pages, each dedicated to one type of information.

### Personal Details

The personal details page identifies the student. It is how the instructor confirms whose booklet it is before recording any information.

<div className="mx-auto max-w-sm">

![Booklet Personal Details page](/booklet/purple_students_details.png)

</div>

| Field | What it records |
| ----- | --------------- |
| Photo | Photo of the student in civilian or sports attire. |
| Name | Student's full name. |
| Military Number | Student's military number. |
| Emirates ID | Emirates identity document number. |
| Date of Birth | Date of birth. |
| Weight | Student's weight. |
| Height | Student's height. |
| Sports Suit Size | Sports suit size. |
| Kimono Size | Kimono size. |

<Callout type="warn">

The page footer states that the booklet is an **official document** and must be preserved. If it is lost, notify the general Jiu-Jitsu supervising officer so the necessary measures can be taken.

</Callout>

### Jiu-Jitsu Exams

This is the page where the instructor checks which **stripe** the student holds and **when** each test was taken.

Since each belt has its own booklet, this page records only the tests of the current belt. The example below is from the **Purple Belt** booklet.

![Booklet Jiu-Jitsu Exams page](/booklet/purple_test.png)

The table is read from **right to left**, following the student's progression:

| Column | What it records |
| ------ | --------------- |
| Stripe 1 to Stripe 4 | The test for each stripe within the current belt. |
| Jiu-Jitsu Rules Test | The written rules exam. |
| Next belt | The promotion test to the next belt — in the example, the Brown Belt. |

When the student passes, the corresponding cell receives a stamp marked **PASS** with the **date of approval**. This date is how the instructor identifies when each stripe was earned.

<Callout type="info">

To find out how many classes and competitions are required before each of these tests, see [Test Requirements](../test/test-requirements).

</Callout>

### Competitions

This is the page where the instructor confirms **how many competitions** the student has taken part in and **which** ones they were.

![Booklet Competitions page](/booklet/purple_competition.png)

This table is also read from **right to left** and holds up to five records per page.

| Column | What it records |
| ------ | --------------- |
| Competition Name | Name of the competition. |
| Competition Date | Date the competition took place. |
| Competition Location | Location of the competition. |
| Result | Placement achieved by the student. |
| Stamp and Approved by | Validation stamp for the result. |

<Callout type="warn">

A record is only complete when it carries the **validation stamp** with the date in the last column. A record filled in by hand but without a stamp does not prove participation.

</Callout>

<Callout type="info">

The number of competitions required varies by the intended promotion. See [Test Requirements](../test/test-requirements) for the minimum at each belt.

</Callout>

### Class Record

This is the page where the instructor checks **how many classes the student has completed** at the current stripe and, from that, whether they have reached the minimum required to test for the next stripe.

Each stripe has its own set of pages. The header identifies the belt and stripe the record belongs to — in the example, **Purple Belt, Stripe 2**.

![Booklet Class Record page](/booklet/purple_stamps.png)

The cells are numbered and filled from **right to left**, in sequence. Each completed class takes one cell, and the grid goes up to 48.

<Callout type="info">

To count how many classes the student has completed at the stripe, simply count the stamped cells. In the example above, the student has completed **9 classes** at Stripe 2.

</Callout>

#### What each stamp records

| Information | Example |
| ----------- | ------- |
| Class date | 19 AUG 2026 |
| Class time | 7:00 |
| Instructor's PS | PS3230 |
| Instructor's signature | Handwritten over the stamp. |

<Callout type="info">

The minimum number of classes required for each promotion is in [Test Requirements](../test/test-requirements).

</Callout>

### Revision Classes

When a student **fails a stripe test**, they must complete revision classes before retaking it. This is the page where the instructor stamps those classes and checks whether the student has completed what is required.

![Booklet Revision Classes page](/booklet/purple_revision_classes.png)

Just like the class record, each stripe has its own revision grid — in the example, one for Stripe 1 and another for Stripe 2, both identified in the header.

<Callout type="warn">

The page header sets the requirement: **a minimum of three revision classes** in case of failing the test.

The student may only retake the test after those classes have been stamped.

</Callout>

The cells are numbered and filled from **right to left**, and the stamp follows the same format as the class record: date, time, instructor's PS and instructor's signature.

In the example above, the student failed the Stripe 2 test and completed the three revision classes on **21, 22 and 23 September 2026**. The Stripe 1 grid is empty, indicating that they passed that test on the first attempt.
