The stamp is the record that the student attended the class. It is how the instructor proves, class by class, that the minimum requirements for the promotion test have been met.

## What the Stamp Must Contain

![Example of stamps recorded in the booklet](/booklet/stamp.png)

Every stamp must carry the four pieces of information below, in a **clear and legible** form:

| Information | Example |
| ----------- | ------- |
| Class start time | 7:00am |
| Date | 21 SEP 2026 |
| Instructor's PS | PS3230 |
| Instructor's signature | Handwritten over the stamp. |

<Callout type="warn">

All four pieces of information must be legible. If the time, date, PS or signature cannot be identified, the stamp does not prove the class.

</Callout>

---

## Stamping Process

<Steps>
  <Step>

  ### Stamp at the End of the Class

  The instructor must stamp the booklet at the end of every class.

  </Step>

  <Step>

  ### Check the Student's Stripe

  Before stamping, the instructor must check which stripe the student currently holds.

  </Step>

  <Step>

  ### Stamp in the First Available Space

  Once verified, apply the stamp in the **first available space** of the student's current stripe.

  </Step>
</Steps>

---

## Stamping at the Correct Stripe

<Callout type="error">

It is **strictly forbidden** to stamp at the next stripe when the student has already reached the minimum number of required classes but **has not yet taken the test**.

</Callout>

Until the test is taken, the student remains at the current stripe and all classes continue to be stamped there — **even if the total exceeds the required minimum**.

A student at Stripe 2 who has already accumulated the minimum 30 classes but has not yet tested keeps receiving stamps at Stripe 2: the 31st, the 32nd and so on. The next stripe only starts receiving stamps after the test has been taken.

<Callout type="info">

The minimum number of classes for each stripe is in [Test Requirements](../test/test-requirements). To see where each stripe's grids are located, see [Booklet](./booklet).

</Callout>
