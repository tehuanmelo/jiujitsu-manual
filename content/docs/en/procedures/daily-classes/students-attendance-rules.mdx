Students may attend up to **three classes per day**, provided they follow the attendance rules described below.

## Daily Class Limit

The limit is a maximum of **three classes per day**. The classes do **not** need to be in the same period: the student may combine morning and afternoon classes, as long as they follow the attendance rules.

### Example

| Class        | Time          |
| ------------ | ------------- |
| First Class  | 07:00 – 08:20 |
| Second Class | 09:00 – 10:20 |
| Third Class  | 15:00 – 16:20 |

<Callout type="warn">

Attending three classes is **not mandatory**. The student may attend one, two or three classes per day, as long as they follow all the attendance rules.

</Callout>

---

## Rules for Consecutive Classes

Students may attend up to **two consecutive classes** without a break.

To attend a **third class** on the same day, the student must observe a minimum break of **1 hour** between the end of the second consecutive class and the start of the third.

### Example 1

| Class                         | Time          |
| ----------------------------- | ------------- |
| First Class                   | 07:00 – 08:20 |
| Second Class                  | 08:30 – 09:50 |
| Earliest Possible Third Class | **10:50**     |

<Callout type="info">

The third class must start **1 hour after the end of the second consecutive class**.

</Callout>

### Example 2

The order can also be reversed: the student takes one class, observes the 1-hour break and only then takes the two consecutive classes.

| Class                          | Time              |
| ------------------------------ | ----------------- |
| First Class                    | 07:00 – 08:20     |
| Earliest Possible Second Class | **09:20** – 10:40 |
| Third Class                    | 10:50 – 12:10     |

<Callout type="info">

Here the consecutive classes are the **second and the third**. That is why the **1-hour** break is observed before them, right after the end of the first class.

</Callout>

---

## Promotion Tests and Competition Days

On days when a student takes part in a **belt promotion test** or a **competition**, they may attend **only one class** on the same day.
