The **Daily Attendance Form** is the official record of every Jiu-Jitsu class delivered at each training base. It records the instructors responsible for the class, the students present and the class time.

This record proves student attendance, keeps the training history accurate and supports administrative control and audits.

<Callout type="warn">

Recording student attendance is **mandatory** in every Jiu-Jitsu class.

</Callout>

Each instructor must complete the daily attendance record and make sure all information is correct.

## When to complete the attendance

The instructor must complete the record **at the end of each class**, with the full information of all students, the instructors and the training base.

## Required information

### Base and instructor information

- Name and PS number of all instructors present
- Base code and name
- Stamp and signature of the instructor responsible for the class

### Student information

- Student name (in Arabic)
- Student military number
- Current belt and degree
- Class number
- Class start time
- Class end time

## Attendance submission

<Steps>
  <Step>

  ### Deliver it to the unit command

  Deliver the attendance record to the unit command **every day**.

  </Step>

  <Step>

  ### Wait for validation

  The unit command reviews the record and then signs and stamps the form.

  </Step>

  <Step>

  ### File the copy

  After validation, keep a copy of the attendance record:

  - In the Jiu-Jitsu room at the training base.
  - Filed in chronological order by month, for record keeping and audits.

  </Step>
</Steps>
