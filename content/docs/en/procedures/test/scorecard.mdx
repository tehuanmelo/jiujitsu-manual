---
title: Scorecard approval
description: Requirements and procedures for reviewing and signing student scorecards.
---

Before a student is approved for a promotion test, the instructor must review and sign the student's scorecard. By signing, the instructor confirms that the student has met all required prerequisites and is technically prepared for the evaluation.

<Callout type="info">

The scorecard signature is the **instructor's final approval** before a student is authorized to take an official promotion test.

</Callout>

<Callout type="warn">

Never sign a scorecard before verifying all required items.

</Callout>

## Instructor responsibility

Only the instructor is authorized to sign a student's scorecard.

The instructor is fully responsible for verifying that the student meets all requirements before signing the scorecard.

---

## Verification checklist

Before signing the scorecard, verify all of the following items.

### Student information

The student's information must be filled in electronically.

| Requirement | Status |
| ------------ | ------ |
| Student name | **Required** |
| Military number | **Required** |
| Belt and degree | **Required** |
| Handwritten information | **Not allowed** |
| Erased or corrected information | **Not allowed** |
| Illegible information | **Not allowed** |

### Required form fields

Verify that the following fields are already present on the scorecard.

| Field | Location |
| ------ | -------- |
| Scheduling code | Bottom left corner |
| Base stamp | Bottom right corner |
| Responsible officer's signature | Bottom right corner |

![Bottom section of the scorecard with scheduling code, base stamp and officer's signature](/scorecard-bottom.png)

<Callout type="error">

If **any of these fields** is missing, the instructor **must not** sign or approve the scorecard.

</Callout>

### Minimum test requirements

The student must prove that all minimum test requirements have been completed.

Accepted proof includes:

- [Student booklet](../booklet/booklet) with the required stamps.
- System document showing the required number of completed classes.

To check the booklet, count the stamped cells in the grid for the student's current degree. See [Stamping](../booklet/stamping) for how each class is recorded and what a valid stamp must contain.

The instructor must also conduct a **full mock test (pre-test)** covering all techniques listed on the scorecard.

Only students who successfully complete the mock test may have their scorecard approved and signed.

<Callout type="info">

For detailed eligibility requirements, see the [Minimum Test Requirements](./test-requirements).

For **Purple Belt** students, also verify the rules test and the stick and knife classes, which are required for promotion to Brown Belt and recorded on dedicated pages of the booklet — see [Purple Belt](../booklet/purple-belt).

</Callout>

---

## Instructor fields

After completing all verification steps, the instructor must fill in the following fields on the scorecard by hand:

- Base code
- PS number
- Instructor name
- Instructor stamp
- Instructor signature
- Stamp date (approval date)
- Student's test date

![Scorecard header with the fields completed by the instructor](/scorecard-header.png)

---

## Prohibited actions

<Callout type="warn">

**Do not** sign a scorecard if any required item is missing.

</Callout>

A scorecard **must not** be signed if:

- The student's information is incomplete.
- The scheduling code is missing.
- The base stamp or the responsible officer's signature is missing.
- The student cannot prove that the minimum test requirements have been met.
- The student has not successfully completed the full mock test.
- The instructor determines that the student is not technically prepared for the promotion test.

---

## Final approval

By signing the scorecard, the instructor confirms that:

- All required documentation has been verified.
- All minimum test requirements have been met.
- The student has successfully completed the mock test.
- The student is technically prepared for the promotion test.

<Callout type="warn">

Signing a scorecard without completing these verifications compromises the integrity and credibility of the evaluation process.

</Callout>
