---
title: Test requirements
description: Minimum requirements for students to be eligible for promotion tests.
---

Before approving a student for a promotion test, the instructor must verify that the student has completed all classes, competitions and evaluations required for the current belt level.

<Callout type="warn">

A student is **not eligible** for a promotion test until **all minimum requirements** have been completed and verified.

</Callout>

## Requirements by belt level

<Tabs items={['White Belt', 'Blue Belt', 'Purple Belt', 'Brown Belt']}>

<Tab value="White Belt">

| Promotion | Minimum Requirements |
| --------- | ------------------ |
| **Degree 1** | 30 Jiu-Jitsu classes |
| **Degree 2** | 30 Jiu-Jitsu classes |
| **Degree 3** | 30 Jiu-Jitsu classes |
| **Degree 4** | 30 Jiu-Jitsu classes |
| **White Belt → Blue Belt** | • 3 Jiu-Jitsu classes<br />• Participation in **2 competitions** |

</Tab>

<Tab value="Blue Belt">

| Promotion | Minimum Requirements |
| --------- | ------------------ |
| **Degree 1** | 30 Jiu-Jitsu classes |
| **Degree 2** | 30 Jiu-Jitsu classes |
| **Degree 3** | 30 Jiu-Jitsu classes |
| **Degree 4** | 30 Jiu-Jitsu classes |
| **Blue Belt → Purple Belt** | • 3 Jiu-Jitsu classes<br />• Participation in **2 competitions** |

</Tab>

<Tab value="Purple Belt">

| Promotion | Minimum Requirements |
| --------- | ------------------ |
| **Degree 1** | 30 Jiu-Jitsu classes |
| **Degree 2** | 30 Jiu-Jitsu classes |
| **Degree 3** | 30 Jiu-Jitsu classes |
| **Degree 4** | 30 Jiu-Jitsu classes |
| **Purple Belt → Brown Belt** | • 3 Jiu-Jitsu classes<br />• 20 Close Combat classes<br />• Written Rules Test<br />• Participation in **3 competitions** |

</Tab>

<Tab value="Brown Belt">

| Promotion | Minimum Requirements |
| --------- | ------------------ |
| **Degree 1** | 30 Jiu-Jitsu classes |
| **Degree 2** | 30 Jiu-Jitsu classes |
| **Degree 3** | 30 Jiu-Jitsu classes |
| **Degree 4** | 30 Jiu-Jitsu classes |
| **Brown Belt → Black Belt** | • 3 Jiu-Jitsu classes<br />• 30 Close Combat classes<br />• Written Rules Test<br />• Practical Refereeing Test<br />• Participation in **3 competitions** |

</Tab>

</Tabs>

## Instructor responsibility

<Callout type="info">

Before signing or approving a promotion test, the instructor must verify that the student has successfully completed **all items required** for that promotion.

</Callout>

## Important

<Callout type="warn">

Authorizing a promotion test for a student who does not meet the minimum requirements compromises the integrity of the evaluation process.

</Callout>
