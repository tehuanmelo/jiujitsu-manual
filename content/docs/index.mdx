---
title: About this Manual
description: Official guide for instructor procedures, testing, and program administration.
---

This manual is intended to help instructors by providing a reference for the essential procedures of the Jiu-Jitsu Program across all operational bases. It describes the mandatory processes for student attendance, booklet stamping, scorecard completion, testing requirements, and report submission. Following these procedures is essential to ensure teaching quality, administrative organization, and a consistent student evaluation process.
