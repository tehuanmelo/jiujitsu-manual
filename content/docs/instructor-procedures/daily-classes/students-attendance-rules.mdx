title: Classes Rules
description: Rules for daily class attendance and required intervals between classes.
---

Students may attend up to **three classes per day**, provided they follow the attendance rules described below.

## Daily Class Limit

Students may attend a maximum of **three classes per day**.

Classes do **not** have to be in the same period of the day. Students may combine morning and afternoon classes as long as the attendance rules are followed.


### Example

| Class | Time |
| ------ | ---- |
| First Class | 07:00 – 08:20 |
| Second Class | 09:00 – 10:20 |
| Third Class | 15:00 – 16:20 |

<Callout type="warn">

Students may attend **up to three classes per day**. Attending three classes is **not mandatory**. They may attend one, two, or three classes, provided all attendance rules are followed.

</Callout>

---

## Consecutive Classes Rules

Students may attend up to **two consecutive classes** without a break.

If a student wishes to attend a **third class** on the same day, there must be a minimum **1-hour break** after the end of the second consecutive class before the third class begins.

### Example

| Class | Time |
| ------ | ---- |
| First Class | 07:00 – 08:20 |
| Second Class | 08:30 – 09:50 |
| Earliest Third Class | **10:50** |

<Callout type="info">

The third class must begin **1 hour after the second consecutive class has ended**.

</Callout>

---

## Promotion Tests and Competition Days

On days when a student participates in a **belt promotion test** or a **competition**, they may attend **only one class** on the same day.
