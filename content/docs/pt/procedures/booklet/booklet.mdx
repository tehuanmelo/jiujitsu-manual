O booklet é onde fica o registro de aulas do aluno. Ele acompanha o aluno em toda a sua jornada no Jiu-Jitsu: **para cada faixa, um livro**.

É nele que o instrutor encontra as informações necessárias sobre o aluno. Sempre que precisar confirmar a situação de um aluno — antes de uma aula, de um teste de promoção ou de uma competição — o instrutor deve consultar o booklet.

## O que o Instrutor Encontra no Booklet

| Informação | O que indica |
| ---------- | ------------ |
| Faixa e grau | O nível em que o aluno se encontra atualmente. |
| Aulas concluídas | Quantas aulas o aluno já realizou no grau atual. |
| Competições | Em quantas competições o aluno já participou. |

<Callout type="info">

São essas informações que definem se o aluno pode fazer um teste de promoção. Consulte [Requisitos para o Teste](../test/test-requirements) para conhecer os mínimos exigidos em cada faixa e grau.

</Callout>

## Páginas do Booklet

O booklet é organizado em páginas, cada uma dedicada a um tipo de informação.

### Dados Pessoais

A página de dados pessoais identifica o aluno. É por meio dela que o instrutor confirma de quem é o booklet antes de registrar qualquer informação.

<div className="mx-auto max-w-sm">

![Página de Dados Pessoais do Booklet](/booklet/purple_students_details.png)

</div>

| Campo | O que registra |
| ----- | -------------- |
| Foto | Foto do aluno em traje civil ou esportivo. |
| Name | Nome completo do aluno. |
| Military Number | Número militar do aluno. |
| Emirates ID | Número do documento de identidade dos Emirados. |
| Date of Birth | Data de nascimento. |
| Weight | Peso do aluno. |
| Height | Altura do aluno. |
| Sports Suit Size | Tamanho do uniforme esportivo. |
| Kimono Size | Tamanho do kimono. |

<Callout type="warn">

O rodapé da página informa que o booklet é um **documento oficial** e deve ser preservado. Em caso de perda, comunique o oficial supervisor geral do Jiu-Jitsu para que as providências necessárias sejam tomadas.

</Callout>

### Exames de Jiu-Jitsu

É nesta página que o instrutor verifica em que **grau** o aluno se encontra e **quando** cada teste foi realizado.

Como cada faixa tem o seu próprio booklet, essa página registra apenas os testes da faixa em curso. O exemplo abaixo é do booklet da **Faixa Roxa**.

![Página de Exames de Jiu-Jitsu do Booklet](/booklet/purple_test.png)

A tabela é lida da **direita para a esquerda**, acompanhando a progressão do aluno:

| Coluna | O que registra |
| ------ | -------------- |
| Stripe 1 a Stripe 4 | O teste de cada grau dentro da faixa atual. |
| Jiu-Jitsu Rules Test | A prova escrita de regras. |
| Faixa seguinte | O teste de promoção para a próxima faixa — no exemplo, a Faixa Marrom. |

Quando o aluno é aprovado, a célula correspondente recebe um carimbo com a marcação **PASS** e a **data da aprovação**. É por essa data que o instrutor identifica quando cada grau foi conquistado.

<Callout type="info">

Para saber quantas aulas e competições são exigidas antes de cada um desses testes, consulte [Requisitos para o Teste](../test/test-requirements).

</Callout>

### Competições

É nesta página que o instrutor confirma **em quantas competições** o aluno já participou e **quais** foram elas.

![Página de Competições do Booklet](/booklet/purple_competition.png)

A tabela também é lida da **direita para a esquerda** e comporta até cinco registros por página.

| Coluna | O que registra |
| ------ | -------------- |
| Competition Name | Nome da competição. |
| Competition Date | Data em que a competição foi realizada. |
| Competition Location | Local da competição. |
| Result | Colocação obtida pelo aluno. |
| Stamp and Approved by | Carimbo de validação do resultado. |

<Callout type="warn">

Um registro só está completo quando traz o **carimbo de validação** com a data na última coluna. Um registro preenchido à mão, mas sem carimbo, não comprova a participação.

</Callout>

<Callout type="info">

O número de competições exigido varia conforme a promoção pretendida. Consulte [Requisitos para o Teste](../test/test-requirements) para conhecer o mínimo de cada faixa.

</Callout>

### Registro de Aulas

É nesta página que o instrutor verifica **quantas aulas o aluno já realizou** no grau atual e, com isso, se ele já atingiu o mínimo exigido para testar para o próximo grau.

Cada grau tem o seu próprio conjunto de páginas. O cabeçalho identifica a faixa e o grau a que aquele registro pertence — no exemplo, **Purple Belt, Stripe 2**.

![Página de Registro de Aulas do Booklet](/booklet/purple_stamps.png)

As células são numeradas e preenchidas da **direita para a esquerda**, na sequência. Cada aula realizada ocupa uma célula, e a grade vai até 48.

<Callout type="info">

Para contar quantas aulas o aluno já fez no grau, basta contar as células carimbadas. No exemplo acima, o aluno concluiu **9 aulas** no Stripe 2.

</Callout>

#### O que cada carimbo registra

| Informação | Exemplo |
| ---------- | ------- |
| Data da aula | 19 AUG 2026 |
| Horário da aula | 7:00 |
| PS do professor | PS3230 |
| Assinatura do instrutor | Manuscrita sobre o carimbo. |

<Callout type="info">

O número mínimo de aulas exigido para cada promoção está em [Requisitos para o Teste](../test/test-requirements).

</Callout>

### Aulas de Revisão

Quando um aluno **é reprovado no teste de um grau**, ele precisa cumprir aulas de revisão antes de refazê-lo. É nesta página que o instrutor carimba essas aulas e verifica se o aluno já cumpriu o exigido.

![Página de Aulas de Revisão do Booklet](/booklet/purple_revision_classes.png)

Assim como o registro de aulas, cada grau tem a sua própria grade de revisão — no exemplo, uma para o Stripe 1 e outra para o Stripe 2, ambas identificadas no cabeçalho.

<Callout type="warn">

O cabeçalho da página define a exigência: **no mínimo três aulas de revisão** em caso de reprovação no teste.

O aluno só pode refazer o teste depois que essas aulas estiverem carimbadas.

</Callout>

As células são numeradas e preenchidas da **direita para a esquerda**, e a estampa segue o mesmo formato do registro de aulas: data, horário, PS do professor e assinatura do instrutor.

No exemplo acima, o aluno foi reprovado no teste do Stripe 2 e cumpriu as três aulas de revisão em **21, 22 e 23 de setembro de 2026**. A grade do Stripe 1 está vazia, indicando que ele foi aprovado naquele teste na primeira tentativa.
