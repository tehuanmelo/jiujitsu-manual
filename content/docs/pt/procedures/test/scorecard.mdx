---
title: Aprovação do Scorecard
description: Requisitos e procedimentos para revisar e assinar os scorecards dos alunos.
---

Antes de um aluno ser aprovado para um teste de promoção, o instrutor deve revisar e assinar o scorecard do aluno. Ao assinar o scorecard, o instrutor confirma que o aluno cumpriu todos os pré-requisitos exigidos e está tecnicamente preparado para a avaliação.

<Callout type="info">

A assinatura do scorecard é a **aprovação final do instrutor** antes que um aluno seja autorizado a realizar um teste oficial de promoção.

</Callout>

<Callout type="warn">

Nunca assine um scorecard antes de verificar todos os itens exigidos.

</Callout>

## Responsabilidade do Instrutor

Somente o instrutor está autorizado a assinar o scorecard de um aluno.

O instrutor é totalmente responsável por verificar se o aluno atende a todos os requisitos antes de assinar o scorecard.

---

## Lista de Verificação

Antes de assinar o scorecard, verifique todos os itens a seguir.

### Informações do Aluno

As informações do aluno devem ser preenchidas eletronicamente.

| Requisito | Status |
| ------------ | ------ |
| Nome do aluno | ✅ Obrigatório |
| Número militar | ✅ Obrigatório |
| Faixa e grau | ✅ Obrigatório |
| Informações escritas à mão | ❌ Não permitido |
| Informações apagadas ou corrigidas | ❌ Não permitido |
| Informações ilegíveis | ❌ Não permitido |

### Campos Obrigatórios do Formulário

Verifique se os seguintes campos já estão presentes no scorecard.

| Campo | Localização |
| ------ | -------- |
| Código de agendamento | Canto inferior esquerdo |
| Carimbo da base | Canto inferior direito |
| Assinatura do oficial responsável | Canto inferior direito |

![Scorecard Bottom](/scorecard-bottom.png)

<Callout type="error">

Se **qualquer um desses campos** estiver faltando, o instrutor **não deve** assinar ou aprovar o scorecard.

</Callout>

### Requisitos Minimos de Teste

O aluno deve apresentar comprovação de que todos os requisitos mínimos de teste foram concluídos.

As comprovações aceitas incluem:

- [Booklet do aluno](../booklet/booklet) com as estampas exigidas.
- Documento do sistema mostrando o número exigido de aulas concluídas.

Para conferir o booklet, conte as células estampadas na grade do grau atual do aluno. Consulte [Estampa](../booklet/stamping) para saber como cada aula é registrada e o que uma estampa válida deve conter.

O instrutor também deve realizar um **teste simulado completo (pré-teste)** cobrindo todas as técnicas listadas no scorecard.

Somente os alunos que concluírem com sucesso o teste simulado podem ter o scorecard aprovado e assinado.

<Callout type="info">

Para conhecer os requisitos detalhados de elegibilidade, consulte os [Requisitos Mínimos para Testes](./test-requirements).

No caso de alunos de **Faixa Roxa**, verifique também a prova de regras e as aulas de bastão e faca, exigidas para a promoção à Faixa Marrom e registradas em páginas próprias do booklet — consulte [Faixa Roxa](../booklet/purple-belt).

</Callout>

---

## Preenchimento pelo Instrutor

Após concluir todas as etapas de verificação, o instrutor deve preencher manualmente os seguintes campos no scorecard.

| Campo |
| ----- |
| Código da base |
| Número PS |
| Nome do instrutor |
| Carimbo do instrutor |
| Assinatura do instrutor |
| Data do carimbo (data da aprovação) |
| Data do teste do aluno |

## Ações Proibidas

<Callout type="warn">

**Não** assine um scorecard se qualquer item exigido estiver faltando.

</Callout>

Um scorecard **não deve** ser assinado se:

- As informações do aluno estiverem incompletas.
- O código de agendamento estiver faltando.
- O carimbo da base ou a assinatura do oficial responsável estiver faltando.
- O aluno não puder comprovar que os requisitos mínimos de teste foram cumpridos.
- O aluno não tiver concluído com sucesso o teste simulado completo.
- O instrutor determinar que o aluno não está tecnicamente preparado para o teste de promoção.

---

## Aprovação Final

<Callout type="warn">

Ao assinar o scorecard, o instrutor confirma que:

- Toda a documentação exigida foi verificada.
- Todos os requisitos mínimos de teste foram cumpridos.
- O aluno concluiu com sucesso o teste simulado.
- O aluno está tecnicamente preparado para o teste de promoção.

Assinar um scorecard sem concluir essas verificações compromete a integridade e a credibilidade do processo de avaliação.

</Callout>
