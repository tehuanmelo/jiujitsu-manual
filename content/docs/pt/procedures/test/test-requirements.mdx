---
title: Requisitos para o Teste
description: Requisitos mínimos para que os alunos sejam elegíveis aos testes de promoção.
---

Antes de aprovar um aluno para um teste de promoção, o instrutor deve verificar se o aluno concluiu todas as aulas, competições e avaliações exigidas para o nível de faixa atual.

<Callout type="warn">

Um aluno **não é elegível** para um teste de promoção até que **todos os requisitos mínimos** tenham sido concluídos e verificados.

</Callout>

## Responsabilidade do Instrutor

<Callout type="info">

Antes de assinar ou aprovar um teste de promoção, o instrutor deve verificar se o aluno concluiu com sucesso **todos os itens exigidos** para aquela promoção.

</Callout>

## Importante

<Callout type="warn">

Autorizar um teste de promoção para um aluno que não atende aos requisitos mínimos compromete a integridade do processo de avaliação.

</Callout>
