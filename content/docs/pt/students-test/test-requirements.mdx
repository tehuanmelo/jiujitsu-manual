---
title: Requisitos para o Teste
description: Requisitos mínimos para que os alunos sejam elegíveis aos testes de promoção.
---

Antes de um aluno ser aprovado para um teste de promoção, o instrutor deve verificar se todas as aulas, competições e avaliações exigidas foram concluídas para o nível de faixa atual do aluno.

<Callout type="warn">

Um aluno **não é elegível** para um teste de promoção até que **todos os requisitos mínimos** tenham sido concluídos e verificados.

</Callout>

## Requisitos por Nível de Faixa

### Faixa Branca

| Promoção | Requisitos Mínimos |
| ---------- | -------------------- |
| **Graus 1–4** | 30 aulas de Jiu-Jitsu |
| **Branca → Azul** | • 3 aulas de Jiu-Jitsu<br />• Participação em **2 competições** |

### Faixa Azul

| Promoção | Requisitos Mínimos |
| ---------- | -------------------- |
| **Graus 1–4** | 30 aulas de Jiu-Jitsu |
| **Azul → Roxa** | • 3 aulas de Jiu-Jitsu<br />• Participação em **2 competições** |

### Faixa Roxa

| Promoção | Requisitos Mínimos |
| ---------- | -------------------- |
| **Graus 1–4** | 30 aulas de Jiu-Jitsu |
| **Roxa → Marrom** | • 3 aulas de Jiu-Jitsu<br />• 20 aulas de Combate Corpo a Corpo<br />• Teste Escrito de Regras<br />• Participação em **3 competições** |

### Faixa Marrom

| Promoção | Requisitos Mínimos |
| ---------- | -------------------- |
| **Graus 1–4** | 30 aulas de Jiu-Jitsu |
| **Marrom → Preta** | • 3 aulas de Jiu-Jitsu<br />• 30 aulas de Combate Corpo a Corpo<br />• Teste Escrito de Regras<br />• Teste Prático de Arbitragem<br />• Participação em **3 competições** |

## Responsabilidade do Instrutor

<Callout type="info">

Antes de assinar ou aprovar um teste de promoção, os instrutores devem verificar se o aluno concluiu com sucesso **todos os itens exigidos** para aquela promoção.

</Callout>

## Importante

<Callout type="warn">

Autorizar um teste de promoção para um aluno que não atende aos requisitos mínimos compromete a integridade do processo de avaliação.

</Callout>
