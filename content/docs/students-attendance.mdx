title: Students Attendance
description: Daily attendance procedures for Jiu-Jitsu classes.
---

## Mandatory

Student attendance is mandatory for all Jiu-Jitsu classes.

Each instructor is responsible for completing the daily attendance record and ensuring that all information is accurate.

## When to Complete the Attendance

The attendance record must be completed at the end of each class with the full information for all students, instructors, and the training base.

## Required Information

### Base and Instructor Information

- Name and PS number of all instructors present
- Base code and base name
- Stamp and signature of the instructor responsible for the class

### Student Information

- Student name (in Arabic)
- Student military number
- Current belt and degree
- Class number
- Class start time
- Class end time

## Attendance Submission

The attendance record must be submitted to the unit command every day.

After reviewing the attendance record, the unit command must sign and stamp the form.

Once validated, a copy of the attendance record must be:

- Stored in the Jiu-Jitsu room at the training base.
- Filed in chronological order by month for record keeping and auditing.
