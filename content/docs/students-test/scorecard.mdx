---
title: Scorecard Approval
description: Requirements and procedures for reviewing and signing student scorecards.
---

Before a student is approved for a promotion test, the instructor must review and sign the student's scorecard. By signing the scorecard, the instructor confirms that the student has met all required prerequisites and is technically prepared for the evaluation.

<Callout type="info">

A scorecard signature is the **final instructor approval** before a student is allowed to take an official promotion test.

</Callout>

<Callout type="warn">

Never sign a scorecard before verifying every required item.

</Callout>

## Instructor Responsibility

Only the instructor is authorized to sign a student's scorecard.

The instructor is fully responsible for verifying that the student meets all requirements before signing the scorecard.

---

## Verification Checklist

Before signing the scorecard, verify all of the following items.

### Student Information

The student's information must be completed electronically.

| Requirement | Status |
| ------------ | ------ |
| Student name | ✅ Required |
| Military number | ✅ Required |
| Belt and degree | ✅ Required |
| Handwritten information | ❌ Not allowed |
| Erased or corrected information | ❌ Not allowed |
| Illegible information | ❌ Not allowed |

### Required Form Fields

Verify that the following fields are already present on the scorecard.

| Field | Location |
| ------ | -------- |
| Scheduling code | Bottom-left corner |
| Base stamp | Bottom-right corner |
| Responsible officer's signature | Bottom-right corner |

![Scorecard Bottom](/scorecard-bottom.png)

<Callout type="error">

If **any of these fields** are missing, the instructor **must not** sign or approve the scorecard.

</Callout>

### Training Requirements

The student must provide proof that all minimum testing requirements have been completed.

Accepted proof includes:

- Student booklet with the required stamps.
- System document showing the required number of completed classes.

The instructor must also conduct a **full mock test (pre-test)** covering every technique listed on the scorecard.

Only students who successfully complete the mock test may have their scorecard approved and signed.

<Callout type="info">

For detailed eligibility requirements, see the [Minimum Testing Requirements](./test-requirements).

</Callout>

---

## Instructor Completion

After all verification steps have been completed, the instructor must manually complete the following fields on the scorecard.

| Field |
| ----- |
| Base code |
| PS Number |
| Instructor name |
| Instructor stamp |
| Instructor signature |
| Stamp date (date of approval) |
| Student test date |

![Scorecard Header](/scorecard-header.png)



---

## Prohibited Actions

<Callout type="warn">

Do **not** sign a scorecard if any required item is missing.

</Callout>

A scorecard **must not** be signed if:

- Student information is incomplete.
- The scheduling code is missing.
- The base stamp or responsible officer's signature is missing.
- The student cannot provide proof that the minimum testing requirements have been met.
- The student has not successfully completed the full mock test.
- The instructor determines that the student is not technically prepared for the promotion test.

---

## Final Approval

<Callout type="warn">

By signing the scorecard, the instructor confirms that:

- All required documentation has been verified.
- All minimum testing requirements have been met.
- The student has successfully completed the mock test.
- The student is technically prepared for the promotion test.

Signing a scorecard without completing these verifications compromises the integrity and credibility of the evaluation process.

</Callout>
